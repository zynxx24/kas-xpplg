# Instalation

1. Install **Bun**
``` curl -fsSL https://bun.sh/install | bash ```
2. Added **Bun** to **Path**
```source /home/codespace/.bashrc```
3. Install **Requirements**
``` cd x-kas ```
``` bun install ```
4. Test **View**
``` bun dev ```
